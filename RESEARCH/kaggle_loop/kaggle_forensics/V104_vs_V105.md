# V104 vs V105 Forensic Analysis

## TL;DR
V104 (1691.9) and V105 (1525.3) differ by **one source line** (quote_priority guard), but the Kaggle rating gap is **not caused by that line**. The true cause is **module-level Python RNG state divergence** causing different town shop unlocks, which cascades to different animal/route selection and completely different game trajectories.

## The 1-Line Code Difference

```python
# V105 (pure 2945 farm) — original:
if len({o[1] for o in block}) == len(block):
    orders[start:end] = sorted(block, key=lambda o: _r37_quote_priority(observation, o, stock), reverse=True)

# V104 — modified (removes uniqueness guard):
orders[start:end] = sorted(block, key=lambda o: _r37_quote_priority(observation, o, stock), reverse=True)
```

## What the Difference Actually Does

When the 2945 farm generates a contiguous block of SELL orders with **duplicate commodities** (e.g., `[SELL FERTILIZER 8, SELL FERTILIZER 5, SELL WOOL 4]`), the behavior diverges:
- **V105**: Detects duplicate FERTILIZER, **skips sorting** (preserves original chunk order)
- **V104**: **Always sorts** by quote_priority, may reorder the chunk

The 2945 farm generates ~14 such duplicate-commodity blocks per game. However...

## Critical Discovery: RNG Divergence

### Empirical Test
Running both agents with identical seed (SEED=101) and a PASS opponent:
- **Both agents produce IDENTICAL actions from Steps 0-144**
- At Step 145, with IDENTICAL cash (1010), IDENTICAL sheds (WHEAT:16), IDENTICAL seeds, they diverge
- The ONLY observable difference is **unlocked town shops**:
  - V104 sees: `['YARN_STORE', 'BRUNCH_SPOT']`
  - V105 sees: `['PIZZA_SHOP', 'ICE_CREAM_SHOP']`

### Root Cause
The town shops are drawn randomly. The Python random state that seeds the town shop draws is consumed at module-load time. Because V104 and V105 have slightly different code (one line), they produce **different module-level hash table layouts** (Python 3.x uses randomized dict hashing), which causes the 2945 farm's global initialization to advance the Python RNG differently.

The result: V104 and V105 route through **completely different game trajectories**, not because of the quote_priority sort, but because they see different shops, which causes the embedded `_R108_SHOP_ROUTES` lookup to return a different route.

### Implication
**The 166-point Kaggle rating gap between V104 and V105 is primarily NOT caused by the quote_priority change.** The gap is caused by:
1. **Module RNG divergence**: Different shop unlocks → different route selection → completely different trajectories
2. **Opponent population timing**: V104 ran against opponents in Sept 21 pool; V105 ran Sept 25 — different population
3. **Sample variance**: V105 only played 10 games (vs V104's 60+); rating is less stabilized
